# KiCad board files

Open `sbp_controller_rev_a.kicad_pro` in KiCad 9 or newer, then open the PCB editor.

**This file is a mechanical floorplan template only.** It contains a 100 mm × 70 mm outline and component placement zones, but intentionally contains no electrical footprints, pads, copper nets, tracks, vias, or fabrication layers. It is not a manufacturable PCB. The actual electrical schematic and routed PCB must be completed after regulator, sensor package, shunt, isolation and connector parts are frozen.
